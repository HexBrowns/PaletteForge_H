# PaletteForge_H マニュアル

**PaletteForge_H** は、メイン・サブ・アクセントの 3 色から、役割ごとに並んだ 64 色（8 色相 x 8 段）のパレットを **Light / Dark の 2 枚組**で作り、
AviUtl2 の色設定のパレット（`Default` フォルダの `.palette`）として書き出すプラグイン（Rust 製 `.aux2`）です。
2 枚とも**同じ位置に同じ役割の色**が並ぶので、「字幕の帯は 2 行 2 列目」のように位置で覚えておけば、明るい画面でも暗い画面でも同じ使い方ができます。
キャラクターごとにシード色を登録して、キャラごとのパレットを作れます。

- **バージョン:** 0.2.0（2026-10-10: 最初の公開。PaletteForge から改名）
- **作者:** by HexBrowns
- **必要環境:** AviUtl2 **2.1.7a** 以上

このプラグインが書くファイルは、`Default` フォルダのパレットと、作ったキャラのシード色の台帳（`palettes.json`）だけです。

---

## 開き方

- **表示** メニュー → **PaletteForge_H**（ウィンドウ配置パネルからも選択可）

## 導入

1. [Releases](https://github.com/HexBrowns/PaletteForge_H/releases) から `HexBrowns.PaletteForge_H-v0.2.0.au2pkg.zip` をダウンロードし、AviUtl2 のプレビューへドラッグ&ドロップする
   （手で置くなら、中の `Plugin` フォルダを AviUtl2 のデータフォルダ（既定は `C:\ProgramData\aviutl2`）へコピーする）
2. AviUtl2 を再起動する
3. **表示** メニュー → **PaletteForge_H** でウィンドウを開く

導入されるのは `Plugin\PaletteForge_H\PaletteForge_H.aux2` だけです。

### ビルド（開発者向け）

リポジトリのルートで [aviutl2-cli](https://github.com/sevenc-nanashi/aviutl2-cli) の `au2` を実行します。
`release/` に、AviUtl2 のプレビューへドラッグ&ドロップして導入できるパッケージ（`.au2pkg.zip`）ができます。

```powershell
au2 release
```

## 使い方

1. 左の **台帳** で、作るパレットを選ぶ
   - **Core** — 既定のパレット（キャラを問わず使う 1 組）
   - キャラの名前 — 登録済みのキャラ。選ぶと、そのキャラのシード色を読み込みます
   - **新しいキャラ** — キャラを新しく作る。シード色が初期値に戻り、名前が空になります
2. キャラなら、上の **名前** の欄に名前を入れる（Enter かほかをクリックで確定）。その下に **書き出し先** のファイル名が出ます
3. **メイン** / **サブ** / **アクセント** の色を決める。右の 8x8 のプレビュー（**Light** と **Dark**）と、その下の検証結果がすぐに変わります
4. **パレットに書き出す** を押す。結果はいちばん下の行に出ます
5. AviUtl2 の **色設定** で、上部の切り替えアイコンからパレットを選ぶ（下の「本体のパレットに出す」）

上の **Core（固定）** / **キャラ** の切り替えは、書き出し先だけを変えます。色はそのままです（色を読み込むのは左の台帳で選んだときだけ）。

### 色の決め方

色の行（メイン・サブ・アクセント、セマンティックの 4 色）は、どれも同じ形です。

| 部品 | 使い方 |
|---|---|
| 色のボタン | 押すと色ピッカーが開く。動かした色はすぐに使われます |
| hex の欄 | `rrggbb` の 16 進数で入れる。先頭の `#` はあってもなくてもよく、3 桁の省略形（`f80` = `ff8800`）も読めます。読めない文字を打っている間は、欄の右に赤い **?** が出ます |
| **R** / **G** / **B** | 0〜255。ドラッグで変えるか、数を打つ |

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| **メイン** | 色 | `#7950f2` | メインの行と、ニュートラルの行の色相のもと |
| **サブ** | 色 | `#12b886` | サブの行 |
| **アクセント** | 色 | `#fd7e14` | アクセントの行 |
| **ニュートラル彩度** | 0〜0.015 | 0.008 | ニュートラル（グレー）の行に混ぜるメインの色相の量。0 で無彩色のグレー。スライダーか右の数の欄で変える |
| **セマンティック 4 色を編集** | — | 閉じている | 押すと、成功・注意などの 4 色（下の表の 5〜8 行目）の行が出て、色を変えられます |

hex・名前・R/G/B・ニュートラル彩度の数の欄は、**Enter かほかをクリックしたときに確定**します（打っている途中の文字では色も書き出し先も変わりません）。
入力中に **Esc** を押すと、入力する前の値に戻ります。hex の欄は、読めない文字のまま確定すると元の色のままです。

## パレットの並び

AviUtl2 のパレットは 8x8 = 64 色で、1 行がそのまま 1 色相の 8 段になります。

| 行 | プレビューの表示 | 中身 |
|---|---|---|
| 1 | neutral | ニュートラル（メインの色相をわずかに混ぜたグレー） |
| 2 | main | メイン |
| 3 | sub | サブ |
| 4 | accent | アクセント |
| 5 | success | 成功（初期値 `#40c057`） |
| 6 | warning | 注意（初期値 `#fab005`） |
| 7 | danger | 危険・エラー（初期値 `#fa5252`） |
| 8 | info | 情報（初期値 `#228be6`） |

| 列 | 名前 | 向いている使い方 |
|---|---|---|
| 1 | base | いちばん下の面（背景） |
| 2 | subtle | カード、帯、字幕の背景 |
| 3 | surface | パネル、囲み |
| 4 | border | 罫線 |
| 5 | strong-border | 強い境界、影 |
| 6 | **solid** | **ベタ塗り（その色相の主役の色）** |
| 7 | text-low | 控えめな文字 |
| 8 | text-high | はっきり読ませる文字 |

- **Light** は 1 列目がいちばん明るく、8 列目がいちばん暗い並び、**Dark** はその逆です。役割は同じ列のままなので、Light と Dark を入れ替えても「背景は 1 列目、文字は 8 列目」が保たれます
- プレビューの色にマウスを乗せると、行・列の名前と hex が出ます。列の番号にマウスを乗せると列の名前が出ます

## 検証

プレビューの下に、Light と Dark それぞれの検証結果が出ます。通れば緑で「検証を通過」、通らなければ赤で「未通過 N 件」と、通らなかった内容（8 件まで）が出ます。

| | 確かめていること |
|---|---|
| V1 | 隣り合う段の明るさ（L*）の差が 5 以上ある（段の差が見分けられる） |
| V2 | text-high（8 列目）と base / subtle（1・2 列目）のコントラストが 7:1 以上 |
| V3 | text-low（7 列目）と base / subtle のコントラストが 4.5:1 以上 |
| V4 | 64 色に、まったく同じ色が無い |

- 未通過でも書き出せます。読みやすさの目安として使ってください
- **2 つの行に同じ色を使うと、その 8 色が丸ごと重なって V4 が落ちます。** そのときは色の欄の下に、黄色で `#rrggbb を accent と warning が共有している` のように、どの行同士が同じかが出ます。片方の色を変えるか、**セマンティック 4 色を編集** で差し替えてください

## 本体のパレットに出す

**パレットに書き出す** を押すと、Light と Dark の 2 枚を書き出します。どう反映されるかは、そのパレットが本体に既にあるかで変わります。

| 状況 | どうなるか |
|---|---|
| **既にあるパレット**（前に書き出して、本体を再起動した後） | その場で本体のパレットが更新されます。**再起動は要りません**。色設定でパレットを選び直すと新しい色が見えます |
| **新しいパレット**（初めて書き出したキャラ、名前を変えたキャラ） | `Default` フォルダにファイルを作ります。**本体に出すには AviUtl2 の再起動が 1 回要ります** |

いちばん下の行に、どちらだったかが枚数付きで出ます。

- `2 枚を反映しました（色設定で開き直すと見えます）`
- `2 枚を新規作成しました。反映には AviUtl2 の再起動が要ります`

キャラを増やすときは、名前を決めて一度書き出す → AviUtl2 を再起動、の後は、色を何度変えて書き出してもその場で反映されます。

本体の色設定では、パレットは `Core` と `Chara` の下にまとまって出ます（`Core` → `Light` / `Dark`、`Chara` → `<名前> Light` / `<名前> Dark`）。

### 書き出すファイル

`Default` フォルダ（データフォルダの下。既定は `C:\ProgramData\aviutl2\Default`）に、次の名前で書きます。

| 対象 | ファイル名 |
|---|---|
| Core | `Core.Light.palette` / `Core.Dark.palette` |
| キャラ | `Chara.<名前> Light.palette` / `Chara.<名前> Dark.palette` |

## キャラの管理

- **作る**: **新しいキャラ** → 名前と色を決める → **パレットに書き出す**。台帳に登録されるのは書き出したときです
- **直す**: 左の台帳でキャラを選び、色を変えて **パレットに書き出す**。同じ名前のキャラは上書きされます
- **名前を変える**: 名前の欄を変えて書き出すと、**新しい名前のキャラとして増えます**（前の名前のキャラとパレットは残ります）。要らなくなった方は下の手順で消してください
- **消す**: 台帳でキャラを選び、**このキャラを削除** を押す。台帳からそのキャラを外し、`Default` フォルダの `Chara.<名前> Light.palette` / `Chara.<名前> Dark.palette` を削除します（ごみ箱には入りません）。確かめのダイアログは出ません
- **Core は消せません**

### 台帳（シード色の保存先）

作ったキャラと Core のシード色（メイン・サブ・アクセント・ニュートラル彩度、変えたセマンティックの色）は、
`Plugin\PaletteForge_H\palettes.json` に保存されます。パレットを書き出したときに書き込み、起動したときに読みます。

- 台帳が読めないとき（中身が壊れているなど）は、`palettes.json.broken-（数字）` に名前を変えて残し、空の台帳で始めます。元の中身は退避したファイルに残っています
- 名前を変えて残すこともできなかったときは、その起動の間は台帳を保存しません（読めなかったファイルを上書きしないため）。書き出したときに、いちばん下の行に `パレットは書けたが台帳の保存に失敗` と出ます
- 台帳の色が読めない値になっていたら、その色は初期値で読み込みます

## 注意

- **キャラの名前に使えない文字**: `\` `/` `:` `*` `?` `"` `<` `>` `|` と **`.`（ピリオド）**。AviUtl2 のパレット名は `.` がちょうど 1 個のときだけ「ラベル.名前」に分かれてまとまるので、名前に `.` を入れられません
- 名前は **40 文字まで**です。前後の空白は取り除かれ、空にはできません。使えない名前のときは、書き出し先の代わりに赤で「名前が不正です」と出て、書き出せません
- `Default` フォルダが無いと、新しいパレットは書き出せません（`Default フォルダが見つからない` と出ます）
